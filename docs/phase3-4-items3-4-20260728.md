## 第 4/4 项：BM25 参数配置化

### 方案

将 `retrieval/searcher.py` 中模块级硬编码的 BM25 参数改为可通过 `app.json` 配置，保留默认值兜底。

```
改造前：
_BM25_K1 = 1.5    # 模块级常量，不可配置
_BM25_B = 0.75

改造后：
app.json → retrieval.bm25.k1 → self._bm25_k1（默认 1.5）
app.json → retrieval.bm25.b  → self._bm25_b （默认 0.75）
```

### 代码变更

**文件**：`retrieval/searcher.py`

1. `LocalRetriever.__init__` — 从 `config.app.retrieval.bm25` 读取，默认兜底
2. `_score_chunk()` — 新增 `bm25_k1` / `bm25_b` 参数（默认值保持原有常量）
3. `search()` — 透传实例参数

```python
# 配置示例（可选，不配置时使用默认值）
# app.json:
# {
#   "retrieval": {
#     "bm25": { "k1": 1.2, "b": 0.5 }
#   }
# }
```
