# 长期纠正规则的置顶与豁免

## 适用范围

`corrections.json` 的 `items` 支持 `pinned: true` 与 `pinned_at`。旧记录没有此字段时视为普通项。

**10 条是记忆提取提示词的普通纠正规则选取上限，不是整个记忆库的存储上限。** 第 11 条之后的记录仍在磁盘上；不会因这个切片而被删除。用户画像的 likes、notes 等列表不属于本机制。

## 行为

- 记忆提取提示词：全部置顶项在前，另选最多 10 条普通项。置顶项不占普通名额，即 2 条置顶 + 10 条普通 = 最多 12 条。
- 普通项保持既有顺序；同一分组内顺序稳定，不改写磁盘 JSON 的键顺序。
- 问答纠正规则召回：置顶项无论是否匹配查询都在前，另外按原有相关性逻辑选最多 5 条普通项，不重复计入置顶项。
- `memory-list`：置顶项先显示并标注 `[置顶]`，文本预览额外显示最多 10 条普通项；JSON 返回完整列表。
- `memory-status`：样本为全部置顶项 + 最多 5 条普通项，置顶项有明确标记。
- 自动老化：置顶项不出现在超期列表，也不被自动移入归档。取消置顶后恢复原有老化规则，按**内容更新时间**计算，不因置顶操作重置年龄。
- 正则/LLM 内容更新、CC→Iris 同步、普通合并导入保留已有置顶标记；LLM 与普通 CC 文本不能自行置顶/取消置顶。合并导入明确提供元数据时采用输入值；`memory-import --replace` 仍是完整替换，输入必须携带要保留的标记。
- 置顶不等于确认：不自动设置 `confirmed`，不屏蔽真实冲突，也不禁止用户显式更新或删除。
- 置顶无硬数量上限，所以提示词会随置顶数量增长。只置顶少量长期关键规则。

## 操作

```bash
python scripts/run_cli.py memory-pin --concept '双周报沉淀与发布规则'
python scripts/run_cli.py memory-list --memory-type corrections
python scripts/run_cli.py memory-pin --concept '双周报沉淀与发布规则' --unpin
```

命令找不到概念会明确报错，不创建占位规则。重复置顶幂等，不增加 `update_count`，不改正文或内容更新时间。置顶只作用于 Iris 的长期纠正规则，不改变 Claude Code 自身的记忆加载机制。
