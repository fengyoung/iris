# 谁是卧底 Web 界面使用说明

> v3.39.0 新增功能。基于 `iris undercover-game-web` 命令启动本地 Web 服务，无需额外依赖。

---

## 快速启动

```bash
iris undercover-game-web
```

服务默认监听 `http://127.0.0.1:7862`，浏览器打开即可使用。

可选参数：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `--port` | 7862 | 监听端口 |
| `--host` | 127.0.0.1 | 监听地址 |

```bash
# 示例：指定端口
iris undercover-game-web --port 8080
```

按 `Ctrl+C` 停止服务。

## 界面说明

Web 界面包含四个视图，通过顶部导航栏切换。

### 1. 游戏设置

**参与模型**

每行对应一名玩家，选择角色（`base_model` 或 `adv_model`）与对应的模型 ID。模型列表从 `config/llm.json` 读取。

- 至少需要 3 名玩家
- 同一 `role/model_id` 组合不能重复出现

**游戏图片**

分别上传平民图片（图片 A）和卧底图片（图片 B），支持点击选择或拖拽上传。两张图片必须不同。

支持格式：JPG、PNG、GIF、WebP、BMP。

**游戏参数**

| 参数 | 说明 |
|------|------|
| 卧底数量 | 默认 1，需小于玩家数的一半 |
| 发言顺序 | 每轮轮转（默认）或固定顺序 |
| 随机种子 | 留空则每局随机，填数字可复现同一对局 |
| 运行模式 | **自动**：游戏全程自动运行；**手动步进**：每轮结束后等待点击"下一轮"才继续 |

**裁判模型**

用于游戏结束后异步生成复盘总结的模型。**不能与任何参与玩家相同**——下拉列表会自动排除已选为玩家的模型，若选中的裁判模型被追加为玩家，会立即提示并清空选择。

---

### 2. 观战视图

游戏开始后自动进入观战视图，实时通过 SSE 接收并展示游戏事件。

**顶部状态栏**

显示当前轮次、阶段（描述中 / 投票中 / 已结束）和控制按钮。

**玩家状态栏**

横向排列所有玩家卡片，每位玩家有独立颜色，淘汰后显示划线与 ☠ 标记。

**时间线**

新事件从底部追加，自动滚动。事件分为四种类型：

| 类型 | 样式 | 内容 |
|------|------|------|
| 🔒 思考卡 | 玩家色淡化背景 + 斜体 + "仅观战者可见" | 观察清单（可折叠）、身份自评、置信度、判断依据 |
| 描述卡 | 玩家色左边框 + 白底 | 公开描述 + 回应 |
| 投票卡 | 玩家色淡化左边框 | 投票目标 + 原因 |
| 裁判陈述 | 灰底无色条 | 轮次开始/结束、淘汰通知、游戏结束横幅 |

> **注意**：思考内容是各模型的私有档案，游戏引擎保证模型之间不互相可见（不进入其他模型的 prompt），但观战者可以看到全部思考以获得完整的观战体验。

**手动步进模式**

运行模式选择"手动步进"时，每轮结束后"下一轮"按钮变为可点击状态，游戏等待用户确认后才进入下一轮。

**终止**

点击"终止"按钮立即停止游戏并返回设置页。

---

### 3. 历史对战列表

展示所有已完成的对局，按时间倒序排列，显示日期、胜负、玩家数、卧底数和是否有裁判总结。

点击任意对局进入复盘详情。

---

### 4. 复盘详情

**图片对比**

并排展示本局使用的平民图片和卧底图片，以及最终胜负结果和全部玩家（含身份标注）。

**裁判总结**

游戏结束后由裁判模型异步生成，内容包括：
- 对战概览
- 关键转折点分析
- 各模型表现点评
- 裁判总评

若总结尚未生成完成，显示"生成中"提示，刷新页面可查看最新状态。

**轮次折叠**

点击展开任意轮次查看完整的描述、投票记录，与观战时的时间线样式一致。

**显示私有思考**

复盘默认不展示私有思考（模拟当时观战视角），点击"显示私有思考"切换，展开的轮次会立即重新渲染。

**导出 JSON**

下载完整的 `replay.json`，包含全部私有思考字段，可用于离线分析。

## 数据存储

每局对局数据存储于 `data/games/<game_id>/`：

```
data/games/
├── uploads/                    ← 上传图片暂存区
└── 20260915-143022-a3f7/       ← 单局目录（时间戳+4位随机码）
    ├── civilian.<ext>          ← 平民图片副本
    ├── spy.<ext>               ← 卧底图片副本
    ├── replay.json             ← 完整对局记录（含私有思考）
    └── summary.md              ← 裁判 LLM 总结（异步生成）
```

`replay.json` 包含完整的每轮发言、投票、私有思考和最终结果，可供离线复盘或脚本分析。

## 与 CLI 命令的关系

Web 界面是 `undercover-game` CLI 命令的图形化前端，底层使用相同的 `UndercoverGame` 引擎。CLI 命令不受影响，两种方式可以并行使用。

```bash
# CLI 方式（不变）
iris undercover-game --image-a civilian.jpg --image-b spy.jpg \
  --game-models "base_model/claude-sonnet,adv_model/qwen3.8-max,base_model/deepseek-flash"

# Web 方式（新增）
iris undercover-game-web
```
