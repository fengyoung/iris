# 知遇：领导力行为标准 v1.0

确认日期：2026-11-16。状态：用户确认；作为版本化评价配置的规范来源。配置的机器可读形式在技术设计阶段决定。Project 保留所采用版本快照。

## 共同口径

| 评级 | 含义 |
|---|---|
| 优异 | 明显超出目标岗位与层级要求，在复杂情境中形成可复用方法，取得持续或广泛成效 |
| 优良 | 超出要求，独立处理复杂问题，解释关键取舍并取得明确成效 |
| 良好 | 稳定满足要求，主动处理职责内问题，完整说明过程、结果与改进 |
| 合格 | 达到基本要求，在职责与目标明确时完成任务，提供具体行为事例 |
| 待改进 | 具体证据显示与要求存在明显差距，如关键行为缺失、判断失当或问题反复发生 |

评级相对于目标岗位与层级。个人贡献者可通过项目内行为获得高评价，不以带过团队或更大业务范围为前提。

未考察：本次未涉及。证据不足：涉及但缺少具体行为、结果或必要追问，暂不能评级。二者不计入五档，不折算低分。

## 1. 主动自发，有目标感

考察理解目标、主动识别问题、确定优先级和对结果负责。

| 评级 | 行为锚点 |
|---|---|
| 优异 | 在高度模糊情境识别关键目标，通过验证修正方向，带动相关方形成共识，建立持续有效的推进方式 |
| 优良 | 将模糊目标转为可执行计划，识别职责边界上的重要问题，按价值和约束调整优先级并取得成效 |
| 良好 | 理解任务目的，主动发现障碍或机会，设置里程碑、跟进结果并及时调整 |
| 合格 | 目标清晰时能计划和推进，遇阻主动反馈，说明本人职责与完成情况 |
| 待改进 | 持续依赖逐步指派，无法解释目标，明显偏差不反馈或调整并影响结果 |

示例主问：讲一次无人明确要求但你主动推进的事情，为什么做、如何排序、结果如何？

追问：谁提出目标？本人改变了什么？不做会怎样？如何判断值得？

## 2. Dive Deep，正确决策

考察深入事实、辨别原因、比较方案和不确定条件下的判断，同时看过程和结果，避免以成败倒推质量。

| 评级 | 行为锚点 |
|---|---|
| 优异 | 发现表面解释之外的关键机制，交叉验证假设，合理处理信息缺失，形成经验证有效且可复用的方法 |
| 优良 | 深入复杂问题关键细节，比较收益、成本与风险，用验证支持取舍并设置回退措施 |
| 良好 | 区分现象与原因，用数据事实验证主要假设，解释选择并随新证据修正 |
| 合格 | 说明背景、基本分析与选择理由，掌握本人负责部分细节，识别主要风险 |
| 待改进 | 关键事实不清就下结论，无法解释核心选择，忽略明显反证，错误后仍不验证或修正 |

示例主问：讲一次多个方案间的关键选择，当时知道什么，为什么这样选？

追问：支持事实？排除方案？未知信息？什么证据会改变判断？

## 3. 快速行动，取得结果

考察关键路径、及时推进、排除阻碍和完成交付，同时兼顾质量与风险。

| 评级 | 行为锚点 |
|---|---|
| 优异 | 强约束或高不确定情境下有效突破并取得持续成效，通过流程工具机制显著改善后续交付 |
| 优良 | 识别关键路径，缩减范围或分阶段验证，主动解决重要阻碍，平衡速度质量风险 |
| 良好 | 节奏清晰，处理依赖与延期，完成交付并验证效果，说明结果与行动的关系 |
| 合格 | 按约定交付本人任务，跟踪进度、反馈问题，完成基本验收与收尾 |
| 待改进 | 长期讨论而缺行动，问题暴露过晚，反复可避免延期，牺牲明显质量换取表面完成且缺补救 |

示例主问：时间紧、资源有限但必须交付时，你先做什么，最终交付到什么程度？

追问：舍弃什么？最大阻碍？验证效果？遗留问题？

## 4. 乐于协作，善于推动

考察理解相关方、明确分工、处理分歧与共同目标。外向或健谈程度不是评级依据。

| 评级 | 行为锚点 |
|---|---|
| 优异 | 在利益或目标明显冲突的复杂协作中建立有效合作，取得持续成果并改善协作机制 |
| 优良 | 识别相关方与约束，主动处理分歧，以事实和共同目标推动决策，无直接管理权也能促成行动 |
| 良好 | 对齐目标职责依赖，理解不同意见，同步变化并推动闭环 |
| 合格 | 清楚表达、履行承诺、尊重不同意见，分歧时沟通或合理升级 |
| 待改进 | 重要信息不同步，反复失约，以指责替代解决，持续回避或施压导致协作受损 |

示例主问：依靠其他团队但优先级不一致时，你如何推动？

追问：对方担忧？本人让步？分歧解决？行动带来的变化？

## 5. 选贤育能、打造梯队

仅对要求团队管理能力的岗位启用；其他岗位不适用。考察选人、授权、发展与降低个别人员依赖。

| 评级 | 行为锚点 |
|---|---|
| 优异 | 前瞻识别能力缺口，培养关键岗位后备，以选拔授权发展机制改善结构，形成持续人才供给 |
| 优良 | 按任务配人，以具体反馈、挑战任务和授权培养成员，有成员成长和团队改善证据 |
| 良好 | 清楚成员优势和发展需求，合理分工、持续辅导反馈，说明措施与效果 |
| 合格 | 解释选人依据，明确目标职责，进行必要辅导，处理常见人员与绩效问题 |
| 待改进 | 标准模糊或失配，长期代替团队完成，缺少反馈培养，不处理持续缺口并影响交付 |

示例主问：讲一位你亲自培养或调整使用方式的成员，如何判断、行动，后来怎样？

追问：与管理行动的关系？授权如何增加？未达预期怎么办？关键成员离开如何承接？使用匿名事例，无需披露成员敏感资料。

## 6. 人选是否简单正直、乐观激情

观察：如实说明贡献、局限和失误，区分事实与推测，承担本人责任；承认困难并持续采取建设性行动；对工作有具体持续投入。

不以兴奋、外向或无条件积极为标准；谨慎、内向不构成负面证据。

| 评级 | 行为锚点 |
|---|---|
| 非常符合 | 充分具体事例表明能坦诚说明贡献和失误，困难中持续建设性行动，对工作持续投入 |
| 一般符合 | 具体事例基本符合，未见明确反向证据，但覆盖或表现强度有限 |
| 不符合 | 经追问仍成立的明确反向证据，如冒领成果、故意隐瞒关键事实或反复推卸本人责任 |

允许未考察、证据不足。未发现问题不等于一般符合。矛盾表述应先排除事实、转写和表达差异。只评价本次面试中的行为，不作绝对人格断言。本项无自动淘汰门槛。

## 录用标准检查

| 层级/条件 | 要求 |
|---|---|
| 基层 | 第 1—4 项均至少合格 |
| 中层 | 第 1—4 项中至少两项良好，其余至少合格 |
| 中高层 | 第 1—4 项中至少两项优良，其余至少良好 |
| 有团队管理要求 | 第 5 项至少合格 |

高于阈值的评级视为满足。关键项未考察或证据不足时显示尚无法确认达标，不自动判低分。标准检查是提示，最终面试结论由用户修改和确认。

每项输出：建议评级、评价理由、支撑片段、反向证据或待验证项。岗位层级显式确认，不自动映射其他职级档。
