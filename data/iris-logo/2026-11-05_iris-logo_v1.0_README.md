## 设计参数

- 图标画板：96 × 96，圆角 14；保持确认版本的放射曲线、底部端点水平对齐及外轮廓居中。
- 主色渐变：#858585 → #c7c7c7 → #ffffff；反色：#7a7a7a → #383838 → #000000。
- 字标：IRIS 全大写，以 Helvetica Neue Medium 字形构建，字号基准 48、额外字距 5；已转路径，无外部字体依赖。
- 图标与字标间隔 24；字标按实际字形外轮廓垂直居中。组合原稿背景透明。
- 建议最小尺寸：独立图标 24px，16px 仅用于 favicon；横向组合以图标高度 32px 及以上使用。
- SVG 为可缩放矢量原稿，勿拉伸比例、改动局部弧度或给标志叠加投影。
- 字体文件不随包分发；如以后替换字型，请确认所选字体的授权。
