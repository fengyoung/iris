# 知遇 · Iris-interview 品牌资产 v1.0

确认日期：2026-11-16。

## 品牌

- 中文名：知遇。
- 英文标识：Iris-interview（大小写与连字符固定）。
- 定位：面试官个人使用的 Mac 本地面试工作台。
- 图形：B 优化版，继承 Iris 三条虹翼原始曲线、横向黑白渐变和 96 × 96、圆角 14 的底板。下方为两列两行长短线，表达简历内容与面试问题对齐。
- 短线宽 3.2，圆头；左右两列共用行基线。

## 默认使用

用户认可图形，并表达更喜欢反色版本。因此默认应用图标、Dock、应用内品牌入口优先采用 **icon-inverse**：白色圆角底板、深色虹翼和对齐符号。

`primary/inverse` 文件名描述色彩版本，并不代表默认优先级。白色底板在透明浅背景上可能不明显；组合字标按背景选用：浅背景使用黑字 primary，深背景使用白字 inverse。不在默认图标上增加未审阅的描边或阴影。

## 文件

- `icon-inverse.svg/png`：默认图标，PNG 为 1024 × 1024 RGBA。
- `icon-primary.svg/png`：黑底备选图标。
- `lockup-primary.svg/png`：图标与黑色英文标识，适合浅背景。
- `lockup-inverse.svg/png`：图标与白色英文标识，适合深背景。
- `Iris-interview.icns`：由反色 PNG 生成的 macOS 多分辨率图标。
- `review-board.png`：确认图形的审阅板；不是单独的生产图标。
- `verification.json`：SVG 路径、字体转曲和原始虹翼保留检查。

SVG 背景透明，圆角底板为图形自身的一部分。英文标识沿用 Iris 的 Arial Rounded MT Bold、42 字体单位圆角加厚和几何右倾 8°，全部转为路径，不依赖安装字体。中文名目前作为产品显示名称，不将审阅板中的中文标题视为已经定稿的中文组合字标。

## 来源与校验

参考 Iris v1.4 与 Iris-caption v1.0 的品牌规范。三个虹翼路径与 Iris 原资产一致，新增的是底部对齐符号。四份 SVG 无 text 节点；图标 PNG 的尺寸、RGBA 与透明角通过检查；ICNS 可解码并包含多分辨率表示。小尺寸下对齐符号较弱，以虹翼轮廓承担主要品牌识别。
