你是一个战略规划文档的结构化解析器。请从以下部门 OP 规划文档中，提取每个战略方向的精炼定义。

## 原始文档
{{op_doc}}

## 输出要求

返回严格的 JSON 对象（不要用代码块包裹），结构如下：

```json
{
  "directions": [
    {
      "id": 1,
      "name": "方向一：xxx（完整标题，含冒号后的描述）",
      "strategic_quote": "OP文档中该方向的战略定位句（原文引用，一句话）",
      "scope_summary": "该方向覆盖的子领域、应用场景、责任范围（2-3句话概括）",
      "key_indicators": ["指标1", "指标2"],
      "sub_areas": [
        {"name": "子领域名", "owner": "责任人", "goal": "目标概述"}
      ]
    }
  ]
}
```

规则：
1. 方向名从 `## O1：` `## O2：` 或 `## 方向N：` 标题提取，去掉「O1：」「方向一：」前缀后作为精炼的简称。例如「O1：检测技术升级…」→ 简称「质检流程智能化」
2. strategic_quote 从方向标题下的引用块或首段提取
3. scope_summary 综合该方向下所有子领域的描述
4. key_indicators 提取该方向明确提到的量化目标指标
5. sub_areas 从 `### KR1：` / `### N.N` 子章节提取，按优先级 KR 编号顺序保留（KR1 > KR2 > KR3…），保留责任人姓名；**同属一个 KR 下的多个 KP 不拆分成独立 sub_area，合并为一个描述**。**owner 字段使用数组格式**：如多个责任人，用 `["张三", "李四"]` 而非 `"张三/李四"`；单人则为 `["张三"]`
6. 文档中可能有 3-4 个方向，全部提取
