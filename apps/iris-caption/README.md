# 声笺 · Iris Caption

Iris 仓库内的独立 macOS 会议字幕应用。当前版本 **0.4.0**，为开发预览，尚未通过真实会议和 M1 / 8GB 的最终验收。声笺版本独立于主项目 Iris。

从 macOS 应用菜单“关于声笺”或设置底部入口查看版本、构建号与日期，并复制反馈信息。更新记录见 [CHANGELOG.md](CHANGELOG.md)，发布与回退制品规则见 [RELEASE.md](RELEASE.md)，数据迁移与恢复见 [数据兼容与恢复](docs/data-compatibility.md)。

## 会议室分段与说话人区分

流式语音检测直接参与起止，默认400ms句首缓存、700ms停顿结束、11秒后寻找短停顿、19秒硬上限。长段带400ms识别上下文；当前模型没有字词时间戳，定稿采用非重叠所属音频的保守回退，仍不能保证硬切点不丢字。

说话人功能默认关闭：设置中安装“会议说话人区分模型”（约34MB），启用试验开关，下一场会议生效。本场可显示A/B等标签，通过设置菜单管理姓名，通过片段“说话人…”修改并锁定归属。声音特征只在本场内存中使用，不跨会议保存。

短插话、低质量或多人混合会标为未确定；重叠讲话显示“可能不完整”。单麦克风不是多人语音分离器；换人检测可能延迟约数秒，不能保证切点精确。公开样本中也有干净单人语音被保守拒识。详情与模型来源见 [说话人模型与验证](docs/speaker-models.md)。

## Apple 风格界面更新

当前界面采用 Apple design-md 参考的浅灰与白色层次、蓝色操作强调和 macOS 系统字体。针对桌面字幕场景调整了工具栏、字幕阅读区、设置与资料窗口，具体适配见 [DESIGN.md](DESIGN.md)。

更新时先退出旧版声笺，解压 `Iris-Caption-0.4.0-macos-arm64.zip`，将其中的 `声笺.app` 拖入“应用程序”并替换旧版。模型目录、设置和钥匙串账户保持原有位置。

已应用确认的 B 方案“轻声波”图标。完整主/反色 icon 与 Iris-caption 字标组合在仓库 `data/iris-logo/2026-11-05_iris-caption-logo_v1.0_*` 管理，App 使用对应 PNG/ICNS 副本。按钮状态审查与规则见 [BUTTON_STATES.md](BUTTON_STATES.md)。

## 本地开发

要求 Python 3.11+、Apple Silicon。应用本身不导入完整 Iris。

```bash
cd apps/iris-caption
python3 -m venv .venv
.venv/bin/python -m pip install -e '.[asr,materials,dev]'
.venv/bin/python -m iris_caption.app
```

可使用无录音、无云端调用的演示：

```bash
.venv/bin/python -m iris_caption.app --demo
```

默认不自动开始录音。点击开始后持续收音；支持暂停、继续和结束。选择设备后在下一次开始采集时生效。

收音必须启用 FSMN 语音检测，原先仅按音量触发的模式已取消。未填写检测模型目录时，自动检查应用已安装模型和已知 Modelscope 缓存，并验证哈希；没有可用模型则提示安装，不自动下载。初稿和定稿都先经过检测，拒绝片段不进入云端校正或字数统计。语音检测不能保证消除所有环境误判；未提高音量门限，也未按重复字删除文字。

设置中可下载固定版本并校验 SHA-256 的 contextual Paraformer、FSMN 语音检测和 MiniLM 语义模型，也可导入已有模型目录。配置 DeepSeek API Key 后启用云端校正，密钥保存在系统钥匙串，不写入设置 JSON。未配置云端密钥时保留本地转写和词典结果。

## 已有界面与服务

- 原文/校正双行或双列、不同配色标签、全屏投屏、字号和历史跟随。
- 独立音频进程、持续采集、自动切段和增量转写。
- 本地规则、云端校正队列、近期上下文和资料检索。
- 手动编辑与确认候选纠错规则；原文保留、迟到结果不覆盖人工修改。
- 手动 Markdown/SRT 导出，关闭前未保存提醒。
- 本地文字/PDF/DOCX 资料、可选长期保留和飞书用户授权接口。
- 知识包及模型完整性校验、原子安装。

## 统计与主页偏好

主页显示本次任务字数，“统计”中可查看历史任务及全局累计。汉字、字母和数字按字符计数，空格、标点不计；转写只统计定稿句段，校正完成字数仅统计已完成云端校正或人工确认的文本，不表示实际改动字数。同一任务重复更新替换原统计，不重复累加。

统计从本版本开始积累，无法补算旧版未保存的会议。历史仅保存随机任务标识、时间、字数和句段数，不保存正文或会议主题。

字号、上下/双列排列、投屏对照选项和麦克风选择会在正式应用下次打开时恢复；麦克风按名称匹配。录音和全屏不会自动开启。人工纠错的“记住纠错”使用“不记住 / 仅本场会议 / 本机长期”三个直接操作按钮，关闭弹窗视为不记住。

## 数据边界

会议文字、音频窗口及待校正队列默认只在内存。不保存录音。只在用户导出后写会议记录；明确保留的资料、规则、模型和设置可以长期存储。

资料默认仅本场。PDF 当前只提取文本层，不提供 OCR。向量模型未配置或不可用时明确降级关键词检索，不将关键词匹配冒充语义检索。临时资料退出即清除；保留的飞书文档再次加载后须重新验证权限/内容才能进入检索。

云端请求包含当前文字、有限近期上下文及少量相关资料片段，不发送音频。

## 飞书个人应用配置

飞书当前文档要求自建应用作为 confidential client 提供 App Secret；没有把共享密钥打包进声笺。使用者须配置个人飞书应用 ID/Secret，密钥存入钥匙串，开通所需只读文档和知识库权限及 offline_access。

注册回调地址：`http://127.0.0.1:8766/callback`。开发预览使用浏览器授权后粘贴完整回调 URL 的方式，应用校验 state 与 PKCE；没有启动本地回调 HTTP 服务，因此浏览器回调页无法连接时仍可复制地址栏。后续可改善此交互。真实租户的授权范围和可用性尚待验证。

## 知识包

使用 `scripts/export_iris_knowledge.py --help` 将已由 Iris 过滤的 ASR 热词/词典/规则制品导出成知识包。脚本不扫描 SOURCE，不导出源文档全文和凭据。支持导入带 manifest/checksums 的知识包 ZIP。通用包、个人长期规则、本场规则分开存储。

## 验证

```bash
QT_QPA_PLATFORM=offscreen .venv/bin/python -m pytest -q
ruff check src tests
QT_QPA_PLATFORM=offscreen .venv/bin/python -m iris_caption.app --smoke-test
```

单元/离屏测试不等于真实收音验证。公开 FunASR 语音样本已在实际 M3 / 16GB 开发机运行 contextual Paraformer + FSMN：5.55 秒音频加速处理约 0.65 秒，模型加载约 2.13 秒，进程峰值 RSS 约 1.30GiB，转写为“欢迎大家来体验达摩院推出的语音识别模型”。这不是麦克风到字幕的端到端延迟，也不替代 M1 / 8GB 或长会议验收。可用 `scripts/benchmark_audio.py` 对指定 WAV 复测。

## macOS 打包

```bash
.venv/bin/python -m PyInstaller IrisCaption.spec --noconfirm
```

产物为 `dist/声笺.app`，个人使用、未 Apple 公证。模型独立于应用包。首次打开可能需系统手动放行；麦克风授权、另一台 Mac 安装及持续 4 小时运行须实机验收。

## 仍需验证的关键项

- M1 / 8GB 上真实音频的 1–2 秒初字目标、人名术语与远场准确率。
- 长句强制切段边界、音频检测阈值、连续推理是否积压。
- ASR 与语义模型共存的内存压力和长会话窗口性能。
- 固定版本模型清单已包含 SHA-256；跨网络完整下载、模型分发许可和实际语义效果仍待验证。
- 真实 DeepSeek/飞书调用和第二台 Mac 的安装权限。

完整需求和阶段计划见仓库 `docs/meeting-live-subtitles-design.md`。
